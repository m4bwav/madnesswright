## Techniques (ranked by usefulness)

81. **Event action sub-fields (completes item 72).** Common targeting block on unit actions: `Location` = SerialNumber of a Room or EventZone (no match = anyone anywhere), `CharParam1.Faction`, `CharParam1.Target` (SerialNumber, Player or Card) with `CharParam1.SerialNumber` / `CharParam1.MadCard`. `SpawnUnit`: Bool1 join an existing squad in the room, Bool2 ignore the card's default weapons, Amount, Location = Door or Spawnpoint SerialNumber, CardRef = Animation MadCard for startup anims, CharParam1.MadCard/Faction/SerialNumber/Awake. `KillUnit`: Bool1 remove instead of kill, Bool2 perma-death for units that normally go Incapacitated. `SwapFactions`: CharParam2.Faction is the new faction. `WakeupUnits`: BoolOp. `SetAIModule`: BoolOp, String1 comma-separated module list. `MoveUnits`: String1 destination Spawnpoint or Door, Amount SUBZERO=ALL. `MakeInvincible`: Bool1 resurrect if dead, Bool2 Unbreakable (takes damage, cannot die) instead, Amount = seconds. `FollowUnit` / `PickUpOrUse`: Bool1 clear other orders, SerialNumber of leader or Interactive/Weapon, PickUpOrUse Bool2 force walk. `SpawnItem`: Bool1 apply ItemParam.StartVelocity, Bool2 sparkle/poof, Location = Spawnpoint or Locker, ItemParam.MadCard/SerialNumber/RandomSpawn/Registered (not junk)/AmQuest (respawns). `KillItem`: Bool1 despawn not break, Bool2 ignore Quest items. `GiveGear`: Int1 slot 0 held / 1 stowed, Int2 hand 0 main / 1 off (off-hand moves to main if empty), Amount max 1 per character, ItemParam.MadCard. `RemoveGear`: Bool1 ignore character qualifiers, Bool2 break armor / despawn weapon. `SetDoorLock`: Bool1 open if possible, Bool2 force open. `SetTogglable`: Bool1 + Int1 sets state-based Togglables to state Int1. `GiveInteractiveTask` / `GiveDestroyTask`: Bool1 pick one PopupComplete at random per object, Bool2 keep them unique. `HealSquad`: Bool1 Medical Cabinet rules, Bool2 skip dead. `ClearAwayWeapons`: Bool1 despawn instantly. `SetRoomLockout`: blank SerialNumber = all rooms. Skill: madnesswright-scenes (stages-and-campaigns.md, the "Actions by group" table from item 72). Source: F1. Confidence: official. In-game test: none.

82. **RunDynamicMethod parameter syntax.** String2 takes comma-separated values: `true`/`false`, strings in apostrophes `'like this'`, whole-number ints, floats with a decimal (`5.0`), vectors as 2-4 floats in parentheses separated by spaces `(0.5 1.0 5.8)`, enums as `Type.Member` (`Faction.AAHW`). The parameter list also picks the overload. Skill: madnesswright-modtools (Harmony code; pairs with item 76). Source: F1. Confidence: official. In-game test: call a one-arg public method on a scene MonoBehaviour with a string and a vector.

83. **CustomObj_Destructible fields.** `Health` (or hit count when `DamageIrrelevant`), `ArmorValue`, `RangedDamageMult`, `WeaponSerialNumber` (only these weapons damage it), allow/deny filters `AllowSources`/`AllowTypes`/`AllowFactions` (true = whitelist, false = blacklist), `failedShotsPassThrough`, `DestructionStates` (objects swapped one at a time as it takes damage; with 2+ the last is full damage), `ShowDamageBar`/`BarAlwaysOnScreen`/`BarFillIsBad` (red), `FlashColorOnHit`, `ResetOnNewTask`, `FailSayLine` (spoken when it cannot be broken), `HitEffect`/`CompletionEffect`/`Explosion` (Explosion MadCard) at `ExplodePoint`, `Heal`/`Heal_Wait`/`Heal_Speed` (regenerating walls), `ResetPathNodes` (recalculate room nav when it opens a path), `SiegeTargetCollider`, `AimTarget`, `IconPoint`, `HitLocations`, and the task-visibility lists `EnabledWhileTask`/`DisabledWhileTask`/`EnabledWhileLocked`/`EnabledWhileUnlocked`/`LockedTaskIgnoresEnabled`. `TaskEvent` runs its EventCard with Conditions SKIPPED. Skill: madnesswright-scenes (scenetools-rules.md; extends item 62). Source: G1 CustomObj_Destructible.cs. Confidence: tooltip text. In-game test: a crate with DestructionStates of 3 meshes and Heal on.

84. **Rooms: lockout and leave-lock rules.** RoomObj `LeaveLockRules` = Default (stages lock doors while enemies are present, hubs do not) / Ignored / Forced; `ForceLockout_PrevRoom`, `DisableLockout_PrevRoom`, `SoftDeactivate` (disable instead of destroy on leaving; avoid). Skill: madnesswright-scenes (scenetools-rules.md). Source: G1 RoomObj.cs. Confidence: tooltip text. In-game test: a hub room set to Forced.

Skill: madnesswright-scenes. Source: G1. Confidence: tooltip text. In-game test: none.

Skill: madnesswright-scenes. Source: G1. Confidence: tooltip text. In-game test: a seat locked to one SerialNumber.
