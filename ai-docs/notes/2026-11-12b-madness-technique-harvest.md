## Techniques (ranked by usefulness)

27. **[Built 2026-11-12, plugin 0.1.25, modtools]** Custom sounds through FMOD banks.** Use FMOD Studio 1.10.11 with the community FMOD sample project. Import each sound as an event (3D for effects and voice lines, 2D for music; G2 notes that a 3D sound made as 2D still works but not the other way round). Use a multi-instrument when a line should pick one of several takes. Assign the events to a new bank, then use File > Save, File > Export GUIDs, File > Build. Copy the Master Bank, the Master strings bank and your own bank into the mod folder, loose, no subfolder. In MadCard Maker make a Soundpack card (melee weapon sounds) or a VoiceSet card (character voice) and paste the GUIDs from the exported GUIDs text file into the slots. Known trap: if you build more than one bank from one project, the sounds stop playing. Use a fresh FMOD project for each extra bank. If nothing plays, delete the project's Metadata and rebuild. Skill: madnesswright-modtools (new references/sounds.md). The skills only mention `fmodPath`/`SoundEvent` names for sounds already in the game. Source: G2, "FMOD - Sounds"; G1 points to LoreRaider's guide (Drive) for the same steps. Confidence: community (G2; G1 agrees FMOD is needed). In-game test: yes.

28. **[Built 2026-11-12, plugin 0.1.25, modtools, scenes]** Custom music: a 2D event with a loop region.** The steps are the same as item 27, except the event is 2D, sits in a folder named after the artist, and has a loop region (right-click between the time bar and the waveform). It then shows up in the Playground Radio and can be set as stage music in Stage_Arena. Skill: madnesswright-modtools sounds reference, cross-link from madnesswright-scenes (stage music). Source: G2, "FMOD - Music" (the author first paraphrased infernalthing, then confirmed it worked). Confidence: community. In-game test: yes.

29. **[Built 2026-11-12, plugin 0.1.25, madnesswright]** Rich text and name tokens in any in-game text (chatter, descriptions).** Unity tags `<b>`, `<i>`, `<color=#RRGGBB>` (named colours such as `Yellow` also work) and `<size=NN>`. A size above about 60 crashes the game, and 80 always does. Name tokens: `[PLAYER]`, `[ENEMY]` (the speaker's current target), `[PSQUAD0..n]` (player squad by order) and `[<serial>]` (the character with that serial number). The skills mention PSQUAD only for scenes. `\n` and `\t` work only when typed into the raw .json, because MadCard Maker doubles backslashes. Skill: madnesswright (references/madcards.md, a "Text" section). Source: G1, Addendum 3. Confidence: community (single guide); the size crash is the author's own claim. In-game test: cheap (a chatter line at size 60, then 61).

30. **[Built 2026-11-12, plugin 0.1.25, madnesswright]** Origin description that looks like a stock one, and hidden special skills.** A SpecialSkill set on the Origin card appears in the origin's description. One set on the origin's Character card works but stays hidden. Put all the skills on the Character, then hand-write `"Description": "BLURB\n\n\t\t\t<color=Yellow>[SPECIAL]</color> <color=White>SKILL TEXT</color>"` in the raw .json. Skill: madnesswright (references/madcards.md, Origin). Source: G1, "Origin.Tips_1" (credited to Geesplei). Confidence: community. In-game test: yes.

31. **[Built 2026-11-12, plugin 0.1.25, modtools]** Custom fonts.** Use a TrueType file (.ttf, not .otf; a font with OpenType variations shows only its first one). Put it in the ModTools project's Fonts folder, add it to an AssetBundle and build. MadCard Maker cannot set a font, so add `"Font": "<font file name without extension>",` by hand to the Chatter card's raw .json, keeping the trailing comma right. `"Style"`: 0 regular, 1 bold, 2 italic, 3 bold and italic. Skill: madnesswright-modtools (SKILL says fonts "need no extra setup" but gives no steps). Source: G1, Addendum 3.1, and G2, "Unity - Fonts" (credits Diggy's font guide). Confidence: community, two guides agree. In-game test: yes.

32. **[Built 2026-11-12, plugin 0.1.25, modtools]** Effect map / texture map colour codes.** The effect map is a copy of the texture painted in key colours. Per G1, the channels mean R = glow, G = shine, B = which tint (126 = untinted), alpha = transparency on glass. G2 gives the palette: black = tint 1, red = tint 1 glowing, green = tint 1 shiny, blue = tint 2, magenta = tint 2 glowing, cyan = tint 2 shiny, navy #00007B = untinted, #FF007B = untinted glowing, #00FF7B = untinted shiny, white = cubemap reflection (Standard +Reflect shader only). The effect map texture must be in the AssetBundle too. The shaders render bright, so darken the base texture to about two thirds. Skill: madnesswright-modtools (references/madobjects.md, materials). Source: G1, Addendum 4, and G2, "Unity - Porting - Textures". Confidence: community, two guides agree on the scheme; G2's RGB and hex values disagree for magenta and pink, so test which one is right. In-game test: yes, one swatch sheet.

33. **[Built 2026-11-12, plugin 0.1.25, modtools]** FBX import scale depends on the Blender version.** Blender 2.79 FBX: Scale Factor 45 with Convert Units ON. Blender 2.8 or later: Scale Factor 0.45 with Convert Units OFF. For animations G2 says 0.45, Convert Units off, and Import Visibility, Cameras, Lights and Preserve Hierarchy unticked. This settles the open "0.45: Scale Factor or object scale?" question from item 22: it is the importer's Scale Factor. Armor (G2): select only the armor in 2.79, parent it to the rig with Ctrl+P "With Empty Groups", weight-paint it, and export the armor and armature together as FBX 6.1 ASCII with Selected Objects. Then set Scale Factor 45 and untick Import Animations. Skill: madnesswright-modtools (animation-events.md line 9 still says unverified; the armor steps). Source: G1, Phase 3.1, and G2, Armor and Custom Animations. Confidence: community, two guides agree. In-game test: yes, a quick check of the 45 / 0.45 pair.

34. **[Built 2026-11-12, plugin 0.1.25, modtools]** Animation export settings from Blender.** In the NLA editor, push the action to a named track on Armature_Main. Do not save the .blend in that state, or you will need a fresh rig file. Export FBX with no object limit, Apply Scalings "FBX All", -Y forward, Z up, Add Leaf Bones off, Animation on with All Actions off. G2 adds that events come in two kinds, Method Events (Function field) and Run Events (String field), and use the Float and Int fields as parameters. That matches item 20. Skill: madnesswright-modtools (SKILL mentions Leaf Bones; check the rest against it before building). Source: G2, "Custom Animations" (2025-12). Confidence: community. In-game test: with the item 20 test.

35. **[Built 2026-11-12, plugin 0.1.25, modtools]** Melee MadObject: right-click > Create Points makes Grip_Main, Grip_Off and MPoint.** MPoint is where the damage comes from. Make the Box Collider cover the whole weapon, give its material the "Items - Weapon" shader, and extract the materials from the FBX. "Create Points" is already in madobjects.md. The point names (Grip_Off, MPoint) and the shader name are not. Skill: madnesswright-modtools. Source: G2, "Weapons - Melee". Confidence: community. In-game test: no (naming only).

36. **[Built 2026-11-12, plugin 0.1.25, modtools]** Inverted normals: flip them in Blender, not with the outline hack.** G2: turn on Face Orientation, select the red faces, Mesh > Normals > Flip, then Shade Smooth (applies to armor, melee and ranged). G1 shows the trap you hit otherwise: inverted normals put the Character - Standard shader's outline inside the mesh, and the only workaround is editing the shader's Outline Width range to allow negative values. Skill: madnesswright-modtools (troubleshooting). Source: G1, Phases 3.1A and 3.2A, and G2, Armor. Confidence: community. In-game test: no.

37. **[Built 2026-11-12, plugin 0.1.25, modtools]** Rig bone uses for armor and AltParts.** Ribs/Abdomen/Chest: outfits, backpacks, the parts of a mask that join an outfit. Arm_Upper/Lower: arm parts. Hands/Fingers: claws, gloves. Head: masks, helmets, goggles. Jaw: only for head parts with a moving jaw (Zed and Abomination bites). Leg_Upper/Lower: outfits. Foot: boots. Root and SyncNodeA: do not weight-paint to them. Skill: madnesswright-modtools. Source: G2, Armor. Confidence: community. In-game test: no.

38. **[Built 2026-11-12, plugin 0.1.25, modtools]** AltParts, alternate materials and alt meshes.** An AltPart (a mirror body part) is built like armor, but with the Body Part component in place of Armor. Unpack the prefab and move the SkinnedMeshRenderer onto the empty that holds the component. To offer AltParts on a character, add `"AltParts": ["Prefab1", "Prefab2"]` to the Character card's raw .json. Alternate textures: in the Armor component, set Material Alts to the number of styles plus the base, with one material slot per mesh. G1 adds that the first mesh and material must also be the first "alt" entry, or the alts cannot be picked in game. Skill: madnesswright-modtools (references/madobjects.md). Source: G1, Phase 3.3 and Addendum 5; G2, AltParts and Alt. Textures. Confidence: community. In-game test: yes.

39. **[Built 2026-11-12, plugin 0.1.25, modtools]** Origin icons are bare textures in the bundle.** Import the icon as a Sprite with transparency, add the texture itself (not an empty holding it) to the AssetBundle, then put the icon's asset name in the Origin card's .json. Skill: madnesswright-modtools / madnesswright (Origin). Source: G1, Addendum 2. Confidence: community. In-game test: yes.

40. **[Built 2026-11-12, plugin 0.1.25, modtools]** Read game assets with AssetStudio (for reference, credit required).** Use AssetStudio 2.2 (github.com/Perfare/AssetStudio). Open a level file from the game folder, not a bundle, so its linked bundles load too. `level58` is the Arena hub and has the most assets preloaded. Export with Model > Export selected objects (split) to get OBJ and PNG. G1 says the developers allow using the game's assets elsewhere if you credit the dev team and link the Steam page. That is G1's report and was not checked against an official statement. Skill: madnesswright-modtools (a new "reference assets" note; keep the credit line). Source: G1, Addendum 1 and Intro. Confidence: single source for the permission, community for the method. In-game test: no.

41. **[Built 2026-11-12, plugin 0.1.25, madnesswright]** Change a subscribed mod's values in the Workshop content folder.** Subscribed mods live in `<SteamLibrary>/steamapps/workshop/content/488860/<itemId>/`. To find a mod's folder, unsubscribe, resubscribe, then sort by date modified. G3 changes an Origin card's `"Imprints"` this way. Caveat: Steam overwrites the folder whenever the item updates, so a lasting change belongs in your own mod with an overriding card. Skill: madnesswright (install/troubleshooting; nothing in the skills mentions the workshop content path). Source: G3. Confidence: community; the overwrite caveat is inferred. In-game test: no.

42. **[Built 2026-11-12, plugin 0.1.25, madnesswright]** MadCard Maker load priority and card types.** The left and right arrows in the mod suite set a card's load priority. A card whose Root is another card in the mod goes up one place automatically. Card types listed in G2 that the skills do not explain: AddonGroups (addons only certain weapons accept), Swatches (colour pairs sold at the Fence), Skins (Arena Loft), VisualStockpiles (unknown even to G2), Stage_Story (G2 calls it mostly deprecated: it can only swap Story levels and Arena stages). Stage_Custom replaced the old `_PG` scene-name suffix. The mod author shown on the Workshop is always the uploader's Steam name, whatever the Author list says. Skill: madnesswright (references/madcards.md; the `Priority` field is already there). Source: G2, "Basics of MCM" parts 1-2. Confidence: community. In-game test: no.

43. **[Built 2026-11-12, plugin 0.1.25, madnesswright]** ModTools and SceneTools now live under the GitHub org MPN-Modders.** Repos: MPN_ModTools (Unity 2019.2.6f1; last push 2026-04-07), MPN_ModTools_Testing, MPN_SceneTools (last push 2026-09-02), MPN_SceneTools_Testing. G2 changed its ModTools link to the new GitHub repo on 2025-09-23. Skill: madnesswright references/sources.md (check that its ModTools and SceneTools links point here; the `_Testing` repos are not mentioned anywhere in the skills). Source: GitHub API. Confidence: official-adjacent (the org hosts the tools the skills already use). In-game test: no.

44. **[Built 2026-11-12, plugin 0.1.25, modtools]** NEM Menu is a BepInEx-style plugin with its own config.** Workshop item 3698923195 ("Not Enough Madness // MENU") adds a cheat menu (F opens the menu, Z teleports you or the selected squadmates). Key bindings are in `%userprofile%/AppData/LocalLow/Gibbing Tree/Madness Project Nexus/ModConfigs/NEMMenu.cfg`. The description says NEM's other features were split into their own plugins. The `ModConfigs` folder is a convention a code mod can follow. Skill: madnesswright-modtools (references/harmony.md, config files). Source: W1 description. Confidence: single source. In-game test: no.
