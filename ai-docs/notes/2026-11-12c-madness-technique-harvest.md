## Techniques (ranked by usefulness)

45. **[Built 2026-11-12, plugin 0.1.26]** Shared config library: the Mod Configuration Module.** W2 is a port of `BepInEx.Configuration` for MPN's own loader. A Harmony mod references its DLL (namespace `NotEnoughMadness.ModConfiguration`), creates `new ConfigFile("<ModName>", true)` and binds typed entries: `config.Bind(section, key, default, description)` returns `ConfigEntry<T>` (bool, float, `KeyCode` seen). Files land in `LocalLow/Gibbing Tree/Madness Project Nexus/ModConfigs/<ModName>.cfg`. The mod must list W2 as a required Workshop item; on first install the user enables it and restarts, or dependent mods error. This replaces the "follow the same convention" guess in harmony.md item 44 with the real mechanism. Skill: madnesswright-modtools (references/harmony.md, "Config files"). Source: W2 description; NEMCameraToggle/Config.cs (https://github.com/NotEnoughMadness/NEMCameraToggle). Confidence: source code plus the author's description. In-game test: yes (a one-key config).

46. **[Built 2026-11-12, plugin 0.1.26]** Workshop load order: Steam > Properties > Workshop, drag to reorder.** W2's author tells users to drag a library mod to the top of the list in the game's Steam Properties > Workshop tab so it loads before the mods that need it. The skills only cover MadCard `Priority` inside one mod. Skill: madnesswright (references/troubleshooting.md, and Step 6 for code mods with dependencies). Source: W2 description. Confidence: single source. In-game test: cheap (two mods, swap the order, read mods.log).

47. **[Built 2026-11-12, plugin 0.1.26]** Harmony pattern: replace a private list in a Postfix with `Traverse`.** NEMUnrestrictedPlayground patches `InteractiveMode.Start` (Postfix), builds `StatCard_Base.ReturnAllCardsByType<StatCard_Character>().ToList()` (and `StatCard_Weapon`), sorts with `.SortCards<T>()` like vanilla, and writes them into the private fields `allDudes_Spawn`, `allDudes_Morph` and `allWeapons` via `Traverse.Create(__instance).Field(name).SetValue(list)`. This un-hides disabled characters and non-store weapons in Playground. Skill: madnesswright-modtools (references/game-recipes.md, Characters or a new "Playground" heading; harmony.md for Traverse). Source: https://github.com/NotEnoughMadness/NEMUnrestrictedPlayground. Confidence: source code (game version not stated; repo pushed 2026-04-10). In-game test: yes.

48. **[Built 2026-11-12, plugin 0.1.26]** Harmony pattern: force a bool method with a skipping Prefix.** MadnessModeUnlocked: `[HarmonyPatch(typeof(UI_StageMenu), "CanPlayHighestDifficulty")]`, Prefix `static bool Prefix(ref bool __result) { __result = true; return false; }`. Unlocks Madness difficulty without a Tough clear. A clean minimal example for the skill's recipes. Skill: madnesswright-modtools (references/game-recipes.md). Source: https://github.com/NotEnoughMadness/MadnessModeUnlocked; W "Madness Mode Unlocked" 3698921952. Confidence: source code. In-game test: cheap.

49. **[Built 2026-11-12, plugin 0.1.26]** Entry-point shape for a mod that adds a persistent behaviour.** NEMCameraToggle's `Main : IModEntrypoint` keeps a static `Harmony("NotEnoughMadness.CameraToggle")`, calls `PatchAll(Assembly.GetExecutingAssembly())` in `Initialize()`, creates one `GameObject` with its MonoBehaviour and `DontDestroyOnLoad`; `Unload()` destroys that object and calls `harmony.UnpatchAll("<same id>")`. harmony.md already names these pieces; this is a public, complete reference repo to link. Also `Directory.Build.props` sets `<Reference><Private>false</Private></Reference>` for every reference at once, so no game DLL is copied into the output. Skill: madnesswright-modtools (references/harmony.md, "Project file" and a link under "Tools"). Source: https://github.com/NotEnoughMadness/NEMCameraToggle. Confidence: source code.

50. **[Built 2026-11-12, plugin 0.1.26]** The vanilla debug mode and its keys.** The game ships a dev debug mode (W3 only switches it on) that reveals hidden doors and objects and enables keys: P logs the current starting scene and entry name; F2 logs difficulty and stage and flies up; Slash + Left Ctrl resets all node paths in the room; Left Shift + Y zooms the camera; ScrollLock combos spawn or kill Creber clones and test JSON overwrites on a new statcard character; M logs (truncated in the API text). Useful for level authors (scene and entry names, node paths) and card authors. The Harmony flag W3 flips is not documented; its source is not in the NEM org. Skill: madnesswright-scenes (Step 6 playtest) and madnesswright troubleshooting. Source: W3 description via GetPublishedFileDetails. Confidence: single source. In-game test: yes, after finding the flag (decomp.py grep for "debug").

51. **[Built 2026-11-12, plugin 0.1.26]** Replacing Assembly-CSharp.dll is the old, incompatible route.** W4 and legacy NEM (G4) ship a patched `Managed/Assembly-CSharp.dll`; such mods are tied to one game build (W4: beta 2.19.k only), are mutually exclusive ("not compatible with Lua for M:PN ... one or the other"), and are removed by Steam "Verify integrity of game files". NEM itself moved to Harmony Workshop plugins in 2026-04. Worth one line in the skills: if a user's mod needs a DLL swap, verify files to undo it, and prefer a Harmony port. Skill: madnesswright (Safety / troubleshooting). Source: W4, G4. Confidence: community, two sources agree.

52. **[Built 2026-11-12, plugin 0.1.26]** Saves break when a mod's content vanishes.** A career that holds custom hirelings or a custom character fails to load after the mod is removed. Fix: reinstall the mod, fire the hirelings (or switch character), then remove it. Skill: madnesswright (troubleshooting.md). Source: G4, "Back up your saves". Confidence: single source (legacy guide), plausible for any mod. In-game test: cheap.

53. **[Built 2026-11-12, plugin 0.1.26]** Workshop Uploader icon rules.** The community uploader wants the icon as PNG or GIF (it rejects JPG), small, 512x512 being the usual size, given as a full path with extension; the content path is the mod's folder under LocalLow/.../Mods. Skill: madnesswright (Step 6 share). Source: G2, "The Basics of MCM, Part 3". Confidence: single source.

54. **[Built 2026-11-12, plugin 0.1.26]** Resource index worth adding to sources.md.** D1 lists tools and tutorials the skills do not link: Slash's Asset Viewer, Pykar's custom trail shader and Game Asset Extraction tutorial, Cturix's sound library, Gibbing Tree "official misc assets" and dialogue scripts, Krinkels' "Modern Blender notes" (Blender 2.8+), Zep's tutorials (custom audio for weapons, projectiles, ranged, melee), BluCop's ranged attachment guide, Bagmetti's animation importing tutorial, Cl4ssic's armor tutorial, Diggy's material and font tutorials, the Event System tutorial ("mission card functions", 2026-03-08), and two Workshop uploaders (Place Name Here Ig's and Soup-o-Stat's GUI). It marks Lua for M:PN OBSOLETE and says ModTools gained Character Refs (2026-04-07) and SceneTools custom Arena stages (2026-03-08). Skill: madnesswright (references/sources.md). Source: D1. Confidence: community index.
